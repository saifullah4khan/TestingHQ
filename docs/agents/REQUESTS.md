# Requests inbox

Nox drops requests here. The planner triages each one into concrete, lane-split,
one-session tasks and routes them to the backlog or the local DISPATCH.md, then
annotates and moves it to Routed / done. Requests are never deleted.

Format:

- [ ] <request in plain language> [optional constraints]
